## Empirical acceptance tests / uncertainty register

Run a per-version/per-surface matrix with a **pre-effect sentinel**: guarded shell creates a file, guarded edit changes a tracked file, guarded local and remote MCP mutate a test fixture, a nested agent invokes each, and any supported computer-use action toggles a harmless fixture. Return deny and assert *no mutation*, agent-visible reason/permitted actions, unchanged CSP state and correct original-tool identity. Repeat with permission-bypass/auto modes and a concurrently executing separate allowed tool. Then kill the daemon, refuse its socket, crash the hook, print malformed JSON, emit no stdout, exit 1 versus 2, exceed each timeout, remove/rewrite project config, and launch an untrusted project; verify actual fail-open/closed behavior independently from documented defaults. Fire parallel same-session calls with incompatible CSP transitions and assert one atomic winner; verify call IDs, ordering of multiple hooks, argument rewrites and retry semantics. Resume, fork, clear, compact, spawn subagents, cancel mid-tool, kill the host before post-hook, and distinguish successful exit from side-effect success. Probe cloud-hook networking and managed-policy tampering separately. Product-specific open questions are Codex hosted/opt-out pathways and trust-skipped hooks; Cline timeout/crash dispositions; Kiro timeout and call-id mapping; Windsurf timeout and complete class coverage; Cursor CLI generic-tool parity and cloud initial-turn hole; Continue CLI installed-source behavior; Roo released status; and SDK bypasses via direct tool calls. No claim here replaces those local observations.
